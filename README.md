# Quiz Master 🧠

A multiple-choice quiz app for practising HTML, CSS and JavaScript. The UI and sample questions are ready; the quiz logic is intentionally unfinished.

## Checklist
- [ ] Start the quiz and render one question at a time
- [ ] Render answer buttons dynamically
- [ ] Allow only one answer per question
- [ ] Highlight correct and incorrect answers
- [ ] Update score and progress bar
- [ ] Show final score and performance message
- [ ] Restart the quiz
- [ ] Save best score using `localStorage`
- [ ] Customize styling and add more questions

## Run
Extract the ZIP, open this folder in VS Code, then open `index.html` in a browser or use Live Server.

## GitHub
Create a repository called `quiz-master`. Then use: `git add .`, `git commit -m "Build Quiz Master"`, `git push`.

## Concepts
Arrays, objects, functions, conditionals, DOM manipulation, events, UI state and localStorage.
